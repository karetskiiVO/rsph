# RSPH

Обобщённая библиотека гидродинамики сглаженных частиц (SPH) на D.
Проект собирается с DMD и DUB и использует стандартную библиотеку D.

```sh
dub build
dub test
dub run
dub build --config=library
```

`dub run` запускает пустую точку входа, соответствующую исходному проекту.
Библиотечная конфигурация собирает те же модули без точки входа.

Модуль `rsph` экспортирует конфигурацию, физические величины и SPH-функции.
Типы домена задают вложенные псевдонимы `Length`, `Time`, `Position` и другие.
Шаблоны `isPhysicsDomain!D`, `isParticle!(D, P)` и `isModel!(D, P, M)`
проверяют соответствие типов требованиям алгоритмов при компиляции.
`Vec3` и `DVec3` предоставляют векторы с компонентами `float` и `double`.

Модуль `rsph.cpu` содержит каркас CPU-бэкенда. Методы
`CPUBuilder.build` и `Config.build_runtime` для CPU пока выбрасывают
`UnimplementedCpuOperation`.
